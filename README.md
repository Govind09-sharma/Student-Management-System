# Student Management System

A simple web-based **Student Management System** built with **Python Flask**, **HTML**, **CSS**, and **SQLite**. The project provides a basic interface for managing student information and is suitable for a college-level learning project.

## Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS
- **Database:** SQLite
- **Development Tool:** Visual Studio Code

## Project Structure

```text
student-management-system/
├── app.py
├── students.db
├── templates/
│   └── index.html
└── README.md
```

> The exact files and folders may differ slightly depending on the version of the project.

## Getting Started

Follow these steps to run the project on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/DevashishDxt123/student-managemant-system.git
cd student-managemant-system
```

### 2. Check Python installation

```bash
python --version
```

If the `python` command is not recognized on Windows, try:

```bash
py --version
```

### 3. Install Flask

```bash
py -m pip install flask
```

### 4. Run the application

```bash
py app.py
```

### 5. Open the application

Open your browser and visit:

```text
http://127.0.0.1:5000/
```

## Database

The project uses **SQLite** to store student information. The database file used by the project is `students.db`.

## Purpose of the Project

This project was created as a college-level project to practise:

- Building a web application with Flask
- Connecting a Python application to an SQLite database
- Creating web pages with HTML and CSS
- Understanding the basic structure of a web application
